# PROYECTO DE DESARROLLO N°1
ESTUDIANTE: Benitez Agustina  
CARRERA: Recursos Digitales  
TEMA: Evolución de las herramientas y tecnologías Front End y Back End y cambios producidos por la incorporación de Inteligencia Artificial como soporte para el desarrollo web durante 2021-2025.

# Sitio web: [[El Desarrollo Web Cambió de Capa](https://benitez-proyecto1.netlify.app)]

# Sobre el proyecto:
Este proyecto consiste en investigar cómo fueron evolucionando las herramientas y tecnologías utilizadas en el desarrollo web durante el período 2021-2025.
El trabajo se divide en tres partes principales: Front End, Back End e Inteligencia Artificial, con el objetivo de observar los principales cambios y tendencias durante estos años.
# Herramientas utilizadas:
1. Perplexity: Utilicé para realizar la investigación inicial del proyecto. Busqué información sobre las principales herramientas y tecnologías utilizadas en Front End y Back End durante 2021-2025, además de información relacionada con la incorporación de Inteligencia Artificial como apoyo para el desarrollo web. La información obtenida fue utilizada como base para realizar los archivos y análisis posteriores.
2. Gemini: Utilicé para organizar y trabajar con la información obtenida durante la investigación.
A partir de esta información se realizaron dos archivos de Excel:
Excel Front End: evolución de herramientas y tecnologías Front End durante 2021-2025.
Excel Back End: evolución de tecnologías y herramientas Back End durante 2021-2025.
También se realizó un archivo de Word sobre los cambios producidos por la incorporación de Inteligencia Artificial como soporte para el desarrollo web.
3. Cuaderno Gemini: Utilicé para analizar en conjunto los dos archivos de Excel y el archivo de Word. El análisis permitió relacionar la información de Front End, Back End e Inteligencia Artificial y observar los principales cambios producidos durante el período 2021-2025. También utilicé este análisis para definir el contenido que posteriormente formaría parte del sitio web.
4. Claude: Utilicé para generar el sitio web a partir de la información investigada y analizada. El sitio fue desarrollado utilizando HTML, CSS y JavaScript.
Se organizaron diferentes secciones sobre Front End, Back End e Inteligencia Artificial, incorporando también gráficos, tablas, comparaciones y una línea de tiempo para presentar la información de forma más clara.
5. Netlify: Utilicé para publicar el sitio web terminado. De esta manera, el resultado final quedó disponible mediante un enlace web para que pueda ser visualizado.
6. GitHub: Utilicé para organizar y presentar el proyecto.
7. Google Drive: Utilicé para guardar los archivos de trabajo realizados durante el proyecto.
# Resultado final:
Como resultado se obtuvo un sitio web que reúne la información investigada y analizada sobre la evolución del desarrollo web entre 2021 y 2025.
El sitio presenta información sobre Front End, Back End e Inteligencia Artificial, mostrando diferentes cambios y tendencias observados durante el período analizado.
También se incorporaron gráficos, tablas, comparaciones y una línea de tiempo para facilitar la visualización de la información.
